Sub-Admin Data Filtering Example

This example demonstrates how to use localStorage to filter data for specific sub-admins.

How to Use:

1. Set a sub-admin ID to filter data for that specific sub-admin:

localStorage.setItem('selectedSubAdminId', '123');

2. Clear the filter to show all data (admin only):

localStorage.removeItem('selectedSubAdminId');

3. Check if a sub-admin is selected:

const selectedId = localStorage.getItem('selectedSubAdminId'); if (selectedId) { console.log('Filtering for sub-admin ID:', selectedId); }

Implementation Details:

  • Backend Changes: All API endpoints now accept a selectedSubAdminId parameter
  • Frontend Changes: All AJAX calls now include the selected sub-admin ID from localStorage
  • Role-based Access:
    • Sub-admins can only see their own data (regardless of localStorage)
    • Admins can see all data or filter by specific sub-admin
